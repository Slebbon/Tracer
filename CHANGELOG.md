# Changelog

## 0.2.0 — 2026-10-02

- First shared versioned release for the VS Code extension and Godot addon.
- README download links and installation instructions for both editors.
- Tagged release workflow builds, tests and publishes both installable packages.
- Explicit session objectives, user-reported outcomes and unresolved / next-step notes.
- Evidence-linked review sections and edit-to-playtest / task-run cadence.
- Recording starts manually; snapshots stop when recording is paused or stopped.
- Godot playtest tracking does not count an already-running scene as a new playtest when recording starts or resumes.
- Saved-session validation recognizes Godot activity and annotation events.
